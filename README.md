# Pirate Token Luck Charm

A one-page luck charm to cast before a Fortnite match while hunting the Pirate Shop token. Press the button, the coin flips, and you get a landing spot, a lucky chest and an omen.

It is a charm for fun only. It cannot add a token to any account. Fan-made, not affiliated with Epic Games.

## Files

- `index.html` is the whole site (styles and script are inside it).

## Put it live on Vercel

1. Create a new repository on GitHub and upload `index.html` and `README.md` to it.
2. Go to vercel.com, choose **Add New > Project**, and import that repository.
3. Leave every setting as it is (Framework Preset: **Other**, no build command) and press **Deploy**.

Any later change you commit to GitHub goes live on Vercel automatically.
